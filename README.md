# R Biostatistics & Health Data Analysis Portfolio

## 📌 Overview
This repository contains a collection of practical projects and coursework developed in **R** (using the *Tidyverse* ecosystem) for Health Data Intelligence. It covers data formatting, cleaning, relational database joins, descriptive/comparative epidemiology, and advanced data visualization.

---

## 📁 Project Structure

### 1. Formatting a Data Table (`01_formatting_a_data_table/`)
* **Objective:** Clean and tidy a dataset by handling missing values, filtering aberrant data, and structuring it according to Tidy principles.
* **Context:** *Collaborative group project*

### 2. Relational Data Joins (`02_jointures/`)
* **Objective:** Master relational data operations and table merging (`inner_join`, `left_join`, etc.) using `dplyr`.
* **Context:** *Individual assignment*

### 3. Descriptive & Comparative Analysis (`03_analyse_infert/`)
* **Objective:** Conduct a descriptive and comparative epidemiological analysis using the `infert` dataset. 
* **Deliverables:** R script and a synthesis presentation (`.pptx`).
* **Context:** *Collaborative group project*

### 4. Advanced Data Visualization (`04_visualisation_ggplot2/`)
* **Objective:** Design clear, publication-ready visualizations using `ggplot2` (including multi-variable mapping, scaling, and formatting).
* **Context:** *Collaborative group project*

### 5. Hospital Consultations Cleaning (`05_hospital_consultations_cleaning/`)
* **Objective:** Real-world data processing pipeline for hospital consultations (`consultations_2025.csv`), focusing on data cleaning, outlier correction, and exploratory insights.
* **Context:** *Collaborative group project*

---
